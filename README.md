# Smart Traffic Violation Reporting System

A full-stack, production-grade web application built with **React.js**, **Express.js**, and **MySQL** for digitally tracking, reporting, verifying, and clearing road traffic violations.

## 🚀 Technologies Used
- **Frontend**: React (Vite), JavaScript, CSS3 (Glassmorphism & Navy Theme), React Router DOM, Axios, Lucide React icons.
- **Backend**: Node.js, Express.js, JWT, bcryptjs, Multer, Helmet, CORS.
- **Database**: MySQL schema (`traffic_violation_system`), indexes, auto-seeding.

## 🛠️ How to Run
```bash
# Install root, backend, and frontend dependencies:
npm run install-all

# Start both backend and frontend concurrently:
npm run dev

# Or run backend & frontend individually:
npm run backend  # http://localhost:5000
npm run frontend # http://localhost:3000
```
